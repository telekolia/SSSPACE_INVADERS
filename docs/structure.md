# SSSPACE INVADERS — устройство проекта

Учебный аркадный шутер на Python и Pygame. Окно — 960 × 960 пикселей,
целевая частота — 60 кадров/с. Игрок движется влево/вправо и стреляет вверх.
Противники идут строем, при выходе за боковую границу меняют направление
и опускаются. После уничтожения строя создаётся следующий.

## Основные файлы

| Файл | Ответственность |
| --- | --- |
| `main.py` | Инициализация Pygame и звука, общее окно, переходы меню → игра → меню; выход только по результату меню `1`. |
| `scenes/main_menu/scene.py` | `MainMenu`: заголовок, кнопки Start и Exit; `startScene()` возвращает `0` для игры и `1` для выхода. |
| `scenes/alien_wave/scene.py` | `AlienWave`: игрок, волны, UI и игровой цикл; `startScene()` возвращает `0` при Escape, закрытии окна или нулевом здоровье. |
| `ui_components/simple_text_button.py` | `Button`: готовые поверхности текста, область клика и отображение наведения. |
| `player.py` | `Player`: движение, здоровье, стрельба и звуки. |
| `bullet.py` | `Bullet`: общая пуля игрока и врагов; движение, попадания и отрисовка. |
| `alien.py` | `Alien`: состояние одного противника, здоровье, область столкновений и отрисовка. |
| `alien_wave.py` | `Wave`: хранение противников по ID, удаление погибших, шаги строя и смена направления. |
| `wave_manager.py` | `WaveManager`: создание строя из пяти рядов по 12 противников и настройка скорости по числу оставшихся. |
| `ui.py` | `UI`: отрисовка имени, счёта и сердечек; хранит отображаемые значения и координаты. |
| `texture_manager.py` | `TextureManager`: загрузка PNG в общий словарь, получение текстур по имени файла без расширения. |
| `res/` | Изображения и звуки. |
| `requirements.txt` | Пока текстовая просьба установить Pygame, а не готовый список зависимостей для pip. |

## Как проходит кадр

1. `main.py` запускает меню; результат `0` создаёт новую игровую сцену, `1` завершает приложение.
2. Игровая сцена вычисляет `dt`, обрабатывает закрытие окна и Escape; они возвращают в меню.
3. `Player.proccess_event` читает клавиши, двигает игрока, обрабатывает стрельбу и пули; попадания уменьшают здоровье противников.
4. `WaveManager.update` создаёт строй при необходимости; `Wave.update` удаляет погибших и двигает строй.
5. UI получает здоровье игрока; при нулевом здоровье сцена возвращает управление в меню.
6. Экран очищается; рисуются противники, игрок с пулями и интерфейс; кадр выводится. Оба цикла ограничены 60 кадрами/с.
7. После игровой сцены `main.py` останавливает звуки и снова запускает меню; следующий Start создаёт новые игровые объекты.

## Подход к разработке

Сейчас это небольшой объектный прототип: сущности хранят своё состояние
и рисуют себя, менеджеры управляют противниками, сцены содержат свои циклы,
а `main.py` переключает сцены. Импорт модулей не запускает сцены и не создаёт шрифты.
Для учебной игры такое разделение понятно; усложнять архитектуру пока не требуется.

- Разделяй данные игры и оформление: здоровье принадлежит игроку, интерфейс его показывает; координаты UI задаются отдельно.
- Зависимости подключаем как модули и обращаемся через их имена: происхождение используемого кода видно на месте вызова.
- Контракты методов и состояние объектов описываем типами, коллекции — с типами элементов; это делает связи понятнее и помогает подсказкам редактора. Простые локальные значения допускают вывод типа из инициализации.
- Развивай по одному небольшому шагу: запуск → видимый UI → связь UI с состоянием → получение урона и начисление очков → завершение игры.
- После шага проверяй конкретный результат. Для здоровья полезны состояния 3, 1 и 0; для UI — положение внутри окна.
- Держи правила движения осознанными: пули движутся с учётом `dt`, игрок и строй — дискретными шагами по таймеру.
- Масштабирование текстур сейчас выполняется при отрисовке. Кэш готовых размеров можно рассмотреть позднее при необходимости.
- Размеры окна, масштаб и границы пока заданы числами в разных модулях; при развитии их удобно согласовать через общие настройки.

## Важные текущие ограничения

- Вражеские пули наносят урон игроку и удаляются после попадания или выхода за экран; счёт UI пока задан константой.
- Закрытие окна во время игры возвращает в меню; закрытие окна в меню, Escape и Exit завершают приложение через результат `1`.
- Области столкновений противников после расстановки обновляются только при шаге строя; шанс выстрела зависит от FPS, пробитие не останавливает перебор целей внутри кадра.
- Пути `res/...` зависят от рабочей папки: запускать следует из корня проекта. В локальном `.venv` проверен Pygame 2.6.1.
